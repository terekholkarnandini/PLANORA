## 1. What is the Planora Dataset?

**PLANORA** is an AI-powered residential floor-plan generation platform. 

The **Planora Synthetic Dataset Generator (V1)** produces high-quality, verified residential floor plans paired with structured specification files and clean 2D vector (SVG) visualizations. Each example in the dataset represents a complete, mathematically validated rectangular house layout that pairs user requirements (plot size, room counts) with exact geometric room placements and door circulations.

In Version 1, the dataset focuses on standard compact urban row house plots:
* **Plot Size**: 20 ft (width) × 40 ft (length) — Total Area: 800 sq ft.
* **Room Program**: 2 Bedrooms, 1 Bathroom, 1 Kitchen, 1 Living Room.
* **Format**: Geometric JSON coordinate files + interactive vector SVG floor plans.

---

## 2. Why Synthetic Floor-Plan Data?

Real-world architectural datasets are notoriously scarce, copyrighted, inconsistent, and often locked in proprietary CAD/BIM formats (`.dwg`, `.rvt`) with noisy scan artifacts.

A rule-based synthetic generator provides critical advantages:
* **Ground Truth Consistency**: Room dimensions, coordinates, boundary limits, and topological connections are 100% mathematically verified.
* **Zero Annotation Noise**: Clear geometric primitives (rectangles, vectors, walls, door locations).
* **Controlled Variety**: Systematic sampling of spatial archetypes (front living, rear garden kitchen, master suites, side corridors) without bias or impossible configurations.
* **Infinite Scalability**: Can generate 10, 100, or 100,000+ distinct examples on demand for training deep learning or generative models.

## 4. How Requirements are Generated

Requirements are defined in structured JSON format (`requirements.json`):

```json
{
  "id": "P001",
  "plot": {
    "width": 20,
    "length": 40,
    "unit": "ft"
  },
  "rooms": {
    "bedrooms": 2,
    "bathrooms": 1,
    "kitchen": 1,
    "living_room": 1
  }
}
```

The generator assigns a unique sequential ID (`P001`, `P002`, ...) and specifies the required room program and plot envelope.

## 5. How Room Layouts are Generated

Layouts are generated in `generator/layout.py` using **6 distinct architectural archetypes** designed specifically for compact residential lots:

1. **`front_living_mid_service_rear_twins`**:
   Full-width front Living Room, central Kitchen and Bathroom utility core, rear private twin bedrooms.
2. **`front_living_and_kitchen_split_rear_bedrooms`**:
   Side-by-side front Living Room and Kitchen, adjacent Bathroom, rear bedrooms.
3. **`front_living_mid_bedrooms_rear_master`**:
   Front Living Room, middle Bedroom 2 & Kitchen, rear private Master Suite with adjacent Bathroom.
4. **`front_living_garden_kitchen_rear_twins`**:
   Front Living Room, middle Bedroom 2 and Bathroom, rear Bedroom 1 and garden-facing Kitchen.
5. **`open_concept_front_living_linear_core`**:
   Open-concept front Living and Kitchen, linear circulation to middle Bedroom 2 and rear Master Suite.
6. **`staggered_private_rear_front_living`**:
   Front Living Room with central service core and rear staggered bedrooms.

### Controlled Variations:
* **Archetype Sampling**: Randomly selects among architectural layout families.
* **Dimensional Jitter**: Partition wall coordinates are varied within safe architectural ranges (e.g. Living Room depths 13–16 ft; Kitchen widths 10–12 ft).
* **Horizontal Mirroring**: 50% probability of reflecting the plan horizontally across the X-axis ($x' = W - (x + \text{width})$), doubling visual diversity.
* **Door Generation**: Computes exact shared wall segments ($\ge 2.5\text{ ft}$) between adjacent rooms and places entrance and interior doors with proper architectural swings.

## 6. Architectural Rules & Constraints

All rules are encapsulated in `generator/rules.py` and are fully configurable:

| Room Type | Minimum Width | Minimum Length | Minimum Area | Key Constraint |
|---|---|---|---|---|
| **Bedroom** | 10 ft | 10 ft | 100 sq ft | Private sleeping quarters; accessible from living/circulation |
| **Living Room** | 10 ft | 10 ft | 100 sq ft | Primary hub; contains main front entrance door |
| **Kitchen** | 8 ft | 8 ft | 64 sq ft | Food prep; adjacent to Living/Dining circulation |
| **Bathroom** | 5 ft | 7 ft | 35 sq ft | Sanitation; minimum 5×7 ft or 7×5 ft |

General constraints:
* Rooms must remain completely inside $[0, \text{plot\_width}] \times [0, \text{plot\_length}]$.
* No two rooms may overlap (interior intersection area must equal 0).
* Every required room must exist with exact counts.
* Circulation/connectivity must be preserved (no isolated rooms).

---

## 7. How Validation Works

The validator in `generator/validator.py` enforces 5 strict tests on every candidate plan:

1. **Boundary Check**:
   $$x \ge 0, \quad y \ge 0, \quad x + \text{width} \le W, \quad y + \text{height} \le L$$
2. **Overlap Check**:
   For any two rooms $A$ and $B$:
   $$\max(A.x, B.x) < \min(A.x_{\max}, B.x_{\max}) \quad \text{AND} \quad \max(A.y, B.y) < \min(A.y_{\max}, B.y_{\max})$$
   If both conditions are true, the rooms overlap and the layout is rejected.
3. **Room-Size Check**:
   Width, length, and total area are checked against `FloorPlanRules`.
4. **Room-Count Check**:
   Counts of each room type must match the requirement specification exactly.
5. **Basic Connectivity Check**:
   An adjacency graph is constructed where an edge exists if two rooms share a wall segment $\ge 2.5\text{ ft}$. A Breadth-First Search (BFS) starting from the Living Room verifies that all rooms are reachable.

### B. One-Click Automated Pipeline & ML Exporter (Recommended):

#### 1. Generate a Specific Lifestyle Preset (e.g. 3B2B with Car Parking, Dining & Balcony):
```bash
python generator/automate.py --count 50 --preset 3b2b_parking_balcony_30x50 --output ./dataset_executive
```

#### 2. Generate a Luxury 4B3B Villa with Car Porch, Utility & Balcony:
```bash
python generator/automate.py --count 20 --preset 4b3b_villa_parking_balcony_40x60 --output ./dataset_villa
```

#### 3. Mixed Variety Dataset (Randomized across ALL plot sizes and room programs):
```bash
python generator/automate.py --count 100 --mixed --output ./dataset_mixed
```

#### 4. Custom Configuration with Specific Lifestyle Rooms:
```bash
python generator/automate.py --count 30 --plot-width 30 --plot-length 50 --bedrooms 3 --bathrooms 2 --parking 1 --balcony 1 --dining 1 --output ./dataset_custom
```

Each automated run produces:
* `dataset/P001/` ... `dataset/Pxxx/` (`requirements.json`, `layout.json`, and `floorplan.svg`)
* `dataset/ml_exports/train_svg.jsonl` (ChatML prompt-to-SVG for LLM fine-tuning)
* `dataset/ml_exports/val_svg.jsonl` (Validation set for LLM fine-tuning)
* `dataset/ml_exports/train_layout.jsonl` (Prompt-to-coordinate JSON pairs)
* `dataset/ml_exports/floorplans_tabular.csv` (Tabular features including all room areas)
* Automatically refreshes [preview.html](file:///c:/Users/DELL/OneDrive/Desktop/planora-dataset/preview.html) with all generated plans!
